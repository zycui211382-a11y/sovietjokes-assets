# Chang'an Guyi C07 cinematic pilot

This directory contains three original 16:9 keyframes made for the C07 cinematic pilot of the *Chang'an Guyi* project:

- `S1_banquet-crack.png`: Lu Zhaolin at a Tang-dynasty night banquet.
- `S2_palace-collapse.png`: civilians fleeing a collapsing Tang palace district.
- `S3_pine-after-ruin.png`: Lu Zhaolin and a pine overlooking the ruined city.

The frames are published here only to provide stable public image URLs to the MiniMax H3 image-to-video API. The analyzed reference video and its sampled frames are not included.
