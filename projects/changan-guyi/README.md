# Chang'an Guyi Ink Action Assets

Public reference assets for the independent animated short film project based on Lu Zhaolin's poem "Chang'an Guyi".

- `style/`: original 2D Chinese ink-action style anchor.
- `characters/`: young Lu Zhaolin character design, informed by the later traditional portrait in *Wanxiaotang Huazhuan* rather than claimed as a contemporary likeness.
- `keyframes/`: eight full-screen 16:9 keyframes, one for each 15-second MiniMax H3 segment.

These assets belong only to the Chang'an Guyi project. They are not Soviet Jokes series assets.

No API keys or private configuration files are included.
