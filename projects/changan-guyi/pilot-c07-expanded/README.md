# Chang'an Guyi C07 expanded cinematic pilot

This directory contains nine original 16:9 full-screen keyframes for the expanded C07 cinematic pilot.

The sequence moves from banquet detail and restrained character performance through large-scale structural damage and civilian evacuation to a quiet ruined-city epilogue. Each file is an independent image-to-video reference, not a storyboard grid.

These files are published only to provide stable public image URLs to the MiniMax H3 API. The analyzed reference video and its sampled frames are not included.
